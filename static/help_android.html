Android

Основные приложения: v2rayNG, NekoBox, Karing, v2rayTun.

Основной способ: установить приложение и нажать «Подключить в 1 нажатие».

Если Play Market не показывает приложение: попробуй другое приложение, проверь регион, можно использовать GitHub releases.

Репозитории: github.com/2dust/v2rayNG, github.com/MatsuriDayo/NekoBoxForAndroid.

Android может попросить разрешить установку из неизвестных источников.
